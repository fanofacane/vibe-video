# 视频项目目录

本目录用于存放今后制作的视频项目，与 `ClawdVideo` 同级，独立于其源码目录。

`ClawdVideo` 保留现有动画项目的代码和参考资源；新制作的视频项目统一放在本目录下，按视频名称建立独立子文件夹。

## 目录结构

```text
当前工作目录/
├── ClawdVideo/                 # 现有动画项目代码与参考资源
└── videos/                     # 今后制作的视频项目
    ├── README.md               # 本说明
    ├── 视频名称一/
    │   ├── README.md           # 该视频的创作说明、制作与导出方法
    │   ├── assets/             # 音频、图片等素材
    │   ├── src/                # 该视频使用的代码或工程文件
    │   └── output/             # 成片、预览和不同导出版本
    └── 视频名称二/
        └── ...
```

## 存放约定

1. 新建视频时，先在 `videos/` 下创建以视频名称命名的文件夹。
2. 一个视频项目的素材、分镜、代码、工程文件和输出成片均存入对应项目文件夹；内部子目录按实际需要创建。
3. 同一视频的不同版本放在同一项目的 `output/` 中，可使用 `视频名称_v01.mp4`、`视频名称_v02.mp4` 等名称区分。
4. 不同视频分别建立项目文件夹，避免素材和生成结果混在一起。
5. 新视频项目不放入 `ClawdVideo/` 内。引用其中的代码或资源时，在对应视频项目的 README 中说明依赖与使用方式。

本说明约定文件组织方式；运行制作或渲染命令时，需要将输出路径设置为对应视频项目的目录。
